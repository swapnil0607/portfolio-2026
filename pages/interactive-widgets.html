Frontend

Interactive widgets built for learning pages and static web experiences.

A set of lightweight HTML, CSS, and JavaScript components designed to make static pages more useful and engaging.

Overview

Component Library

Reusable tabs, filters, cards, accordions, counters, and carousel blocks for learning pages and campaign pages.

Problem

Static Pages Felt Flat

The goal was to add interaction without adding a framework, heavy dependencies, or fragile scripts.

Solution

Native JS Patterns

I used progressive enhancement, class-based states, keyboard-friendly controls, and CSS transitions.

Tools

Stack

HTML, CSS, vanilla JavaScript, IntersectionObserver, accessible states, and modular file organization.
